基本概念

大模型是什么

  • AI（人工智能）：大概念，凡是让机器表现出“智能行为”的技术都算 —— 基于规则、算法或数据做出决策都可以叫 AI，大模型只是其中一种实现
  • 机器学习：不把规则写死，让程序从数据里自己总结规律
  • 深度学习：机器学习的一种，用多层神经网络去学复杂模式
  • 大模型：基于深度学习的系统，由神经网络构成，靠上亿到上千亿的参数记住海量数据里的模式，遇到新输入就预测或生成
  • LLM（大语言模型）：大模型的一个子类，专门做 NLP（自然语言处理），学大规模文本的模式来理解和生成自然语言。语言是人类表达思想的主要方式，所以 LLM 被看作通往 AGI（通用人工智能）的重要方向
  • Transformer：Google 2017 年提出的神经网络结构（论文《Attention Is All You Need》）。它不用 RNN 的循环结构，靠自注意力（self-attention）让每个 token 直接和整句里的其它 token 计算关联，所以能并行训练。原始论文是 Encoder-Decoder 结构，后来分出两条线：Encoder-only（BERT 那类，擅长理解）和 Decoder-only（GPT 那类，擅长生成，现在的主流）
  • 多模态（Multimodal）：能同时处理文字、图片、语音、视频等多种输入输出，不只是文本

模型怎么处理文字

  • Token（词元）：一小段文本（一个词，或词的一部分）。模型按 token 算长度、费用和记忆量
  • 分词（Tokenization）：把文本切成 token 的方式。之所以重要，是因为过滤器和模型可能把同一段文字读成不同的样子，这个差异会成全某些攻击
  • 上下文窗口（Context window）：模型一次能处理多少 token（系统提示 + 历史对话 + 检索内容 + 本轮输入）。超出窗口的内容会被截断，一般先丢最早的对话；系统提示通常会被保留，但不是所有实现都保证

提示词与上下文

  • 提示词（Prompt）：你发给模型的文本，约等于你能控制的输入
  • 系统提示词（System prompt）：开发者给模型定下的隐藏规则，约等于服务端配置，里面常藏着你想要的秘密
  • 用户提示词（User prompt）：用户输入的消息，约等于你的入口
  • 上下文工程：不碰模型权重，只通过“往上下文里放什么”来影响输出 —— 系统提示词、历史对话、检索到的文档、工具返回，都算上下文

RAG 里的几个概念

  • RAG（检索增强生成）：先把问题转成向量，从知识库里按相似度查出最相关的几段，再塞进上下文让模型据此作答，约等于模型在读一个你也许能投毒的数据源
  • 嵌入 / 向量（Embedding / vector）：把文本转成一串数字（向量），语义相近的文本向量距离也近，搜索和 RAG 都靠它
  • 向量数据库（Vector database）：存放并检索那些向量的地方，约等于 RAG 背后的数据库
  • 分块（Chunking）：为 RAG 把大文档切成小块。切得不好，模型拿到的上下文就是乱的，回答也会出错

训练、微调与参数

  • 权重 / 参数（Weights / parameters）：神经网络里可调节的数值，训练就是不停调它、把规律存进去；常说的 7B、70B 指参数量，B = billion（十亿），7B 就是 70 亿个参数
  • 预训练（Pre-training）：拿海量语料做自监督学习，把参数调到能拟合数据。自回归模型（GPT 这类）的目标是“预测下一个 token”，BERT 这类是“盖住一部分词让模型猜”
  • SFT（指令微调）：预训练之后，用“指令 + 标准答案”的数据再训一轮，让模型学会按人的要求回答
  • 对齐（RLHF / DPO）：用人类偏好数据继续调整，让输出更有用、更安全 —— 这一步很大程度决定了模型“听不听话”
  • 微调（Fine-tuning）：在训好的模型上用少量领域数据接着训，让它贴合某个任务；只调一小部分参数的叫 LoRA，省显存

智能体（Agent）

  • Agent（智能体）：能“思考 → 行动 → 观察”以实现目标的自主系统（这套循环常叫 ReAct）；基于 LLM 的智能体可以看成“大脑 + 身体”，大脑用 LLM 推理决策，身体负责调用工具执行
  • 工具 / 函数调用（Tool / function calling）：模型能调用的东西（搜索、邮件、数据库、执行代码），约等于应用的后端函数，由模型决定给它们传什么参数
  • MCP（模型上下文协议）：Anthropic 2024 年提出的一套标准，把工具和数据以统一方式接入智能体；它的服务器和工具描述都可能被攻击
  • 技能包（Skill）：智能体加载的一整包现成指令和代码，里面可能藏着恶意指令

模型、聊天机器人、RAG、智能体的关系

：

  • 模型（LLM）：大脑。读文本、猜下一个词，仅此而已
  • 聊天机器人：模型 + 隐藏规则 + 聊天窗口，能跟你对话
  • RAG 应用：聊天机器人 + 能读取文档和你的数据
  • 智能体（Agent）：模型 + 工具，能真正“动手做事”、分步执行，而不只是聊天

越往右，它能做的事越多

搭建简单的RAG 应用

LangChain

LangChain是一个基于语言模型开发应用程序的编程开发框架，它提供了多种模块，通过这些模块可以构建出一个简单的自主决策、能执行任务的智能体（Agent）

模型（Models）：包含各大语言模型的LangChain接口和调用细节，以及输出解析机制。
提示模板（Prompts）：用户每次输入的 Prompt，都会被选择性的拼接到上下文，形成新的条件，从而引导模型输出。
数据索引（Indexes）：搭建动态的知识库。并使其准备好与语言模型交互（包括文档加载程序、向量存储器、文本分割器和检索器）。
记忆（Memory）：通过短时记忆和长时记忆，在对话过程中存储和检索数据，让ChatBot记住你。
链（Chains）：LangChain中的核心机制，以特定方式封装各种功能，并通过一系列的组合，自动而灵活地完成任务。
代理（Agents）：另一个LangChain中的核心机制，通过“代理”让大模型自主调用外部工具和内部工具，使智能Agent成为可能。

使用RAG搭建知识库

RAG 是“检索外部知识 + 拼 Prompt + LLM 生成”的组合流程。检索阶段使用 embedding 等 AI 模型将问题和知识库转换成向量；通过向量相似度检索算法匹配相关内容；最终将相关内容拼接到输入里面。

短期记忆

每次调用链的时候，LangChain 会把 memory 里的历史对话拼接到 Prompt,所以memory也可以看作提示词工程的一部分

长期记忆

但是memory属于短期记忆，能记多少内容取决于模型的上下文窗口（token）大小，如果提示词加问题过长就会被强制截断
所以我们可以将历史对话储存在本地，使用embedding检索实现长期记忆

提示词注入

在前面的搭建简单的智能体中我们就可以看出，从模型视角：提示词和普通输入没有本质区别，都只是 token。目前的检测手法不是从模型内部实现隔离，而是用外部约束 + 行为训练来降低越狱概率。哪怕是chatgpt这样的顶级的ai，每隔一段时间也会爆出越狱方法。因为目前的检测手段本质上还是黑名单，黑名单永远是不可靠的。

但就我的亲身感受，我在23年对chatgpt进行越狱测试时发现不要太简单，但是在25年时尝试越狱，发现chatgpt越狱对于我来说已经是不可能的事情了

AI 中的 DoS 攻击

可以分为三种，一种就是模型api泄露，如果模型权限过大，外来用户可以要求模型主动去翻看配置文件泄露api
还有一种就是工具权限过大或者没有上限导致资源被滥用
最好一种是模型不会拒绝你，需要在系统提示词中设置，比如外来用户可以说有一个数学题不会，然后出一个千禧年难题来消耗系统资源

常用工具

garak 自动化 LLM 漏洞扫描器，DAN、promptinject、编码、泄露等探针；HTML/JSON 强度报告。
PyRIT（Microsoft） 红队自动化与多轮编排（Crescendo）。
promptfoo 面向应用级注入与智能体的评测 + 红队框架；带安全数据库。
spikee（Reversec） 针对 LLM 应用的定向提示词注入测试。
LLMmap 从回复行为识别模型指纹。
Llama Guard / ShieldGemma 护栏分类器，也拿它们当靶子来测。
L1B3RT4S、ChatGPT_DAN 仓库 社区的越狱/隐藏载荷合集。
RAMPART（Microsoft） pytest 原生的跨提示词注入（XPIA）测试，可接入 CI/CD。
GLiNER Guard 在大模型之前一趟搞定不安全请求 + PII 的快速分类器。
Agent Threat Rules 面向智能体威胁的开放检测规则集（400+ 条），agentthreatrule.org。
CaMeL 防御范式：用能力令牌把控制流与不可信数据分开。
Honeyval 由 LLM 驱动的蜜罐，甚至能反向注入攻击中的智能体。
Awesome-LLMSecOps LLM/智能体安全工具、论文与资源的精选清单。
LLMFuzzer 开源的 fuzz 框架，通过 API 对 LLM 应用做提示词注入。
LLM Hacking Database pdparchitect 收集的真实 LLM 攻击手法与 PoC。
Prompt-Injection-Everywhere TakSec 的载荷清单，用于在各类应用和字段里找注入。
Julius / Augustus（Praetorian） 识别应用用的是哪个模型，再据此发动攻击。
Inject My PDF 把隐藏的提示词注入嵌进 PDF 或简历里（Greshake）。
JailbreakChat 越狱提示词的社区存档，用来测你的过滤器。
